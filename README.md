# 🤖 AI Multi-Agent Systems using AutoGen

A collection of Agentic AI projects built using Microsoft's AutoGen framework and Google's Gemini models.

This repository demonstrates how multiple AI agents collaborate to solve complex real-world tasks using planning, reasoning, tool calling, and teamwork.

# 🛠 Installation

```bash
git clone https://github.com/your_username/AI_MultiAgent_Projects.git

cd AI_MultiAgent_Projects
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create

```
.env
```

Example

```env
GEMINI_API_KEY=YOUR_API_KEY
MODEL_NAME=gemini-3.6-flash
BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
MAX_ROUNDS=60
```
